# Portfolio Project Requirements

## Tech Stack
- React project
- Tailwind CSS for styling
- Lenis for smooth scrolling
- Component-based structure
- Single-page website
- Black background with white text

## Page Structure
The site should have one page with 4 sections:
1. Home
2. Who Am I
3. Portfolio
4. Contact Me

## Navigation
- Top menu includes all 4 sections
- Clicking a menu item scrolls to the relevant section
- When the user scrolls to a section, the URL hash updates to match the section id
- The active section should be visually highlighted in the navigation

## Visual Style
- Dark / black theme
- White text
- Clean, modern, minimal aesthetic
- Strong contrast
- Component-based layout

## Functional Requirements
- Smooth scrolling via Lenis
- Single-page navigation without reloads
- Hash-based URL updates for each section
- Responsive layout preferred
- Simple but polished portfolio homepage
